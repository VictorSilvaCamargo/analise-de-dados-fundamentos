## 📖 Visão Geral

Projetos de análise exploratória de dados (EDA), processamento massivo distribuído com PySpark, modelagem estocástica (Teoria de Filas e Processos de Poisson) e computação fundamental.

Este repositório reúne projetos práticos desenvolvidos com foco em engenharia de dados e inteligência artificial, demonstrando desde fundamentos teóricos até implementações práticas com validação experimental e métricas salvas.

## 🌟 Destaques do Portfólio

### 🔹 [Processamento Massivo de Dados com PySpark](./01_processamento_distribuido_pyspark.ipynb)
Manipulação de grandes volumes de dados (Censo Escolar e Dados de Aeroportos) usando DataFrames distribuídos do Apache Spark.

- **Stack:** `Apache Spark` `PySpark` `Big Data` `Data Wrangling`
- **Notebook:** [`01_processamento_distribuido_pyspark.ipynb`](./01_processamento_distribuido_pyspark.ipynb)

### 🔹 [Modelagem Estocástica e Simulação de Teoria de Filas (M/G/1)](./02_simulacao_teoria_filas_mg1.ipynb)
Simulação probabilística de sistemas de filas M/G/1 e processos de Poisson para análise de capacidade de servidores e tempos de espera.

- **Stack:** `SciPy` `NumPy` `Probabilidade` `Simulação`
- **Notebook:** [`02_simulacao_teoria_filas_mg1.ipynb`](./02_simulacao_teoria_filas_mg1.ipynb)

### 🔹 [Parser e Analisador de Lógica Proposicional](./03_parser_logica_proposicional.ipynb)
Implementação de analisador léxico e sintático para fórmulas da lógica proposicional e geração de tabelas-verdade.

- **Stack:** `Compiladores` `Parsing` `Estruturas de Dados`
- **Notebook:** [`03_parser_logica_proposicional.ipynb`](./03_parser_logica_proposicional.ipynb)

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/VictorSilvaCamargo/analise-de-dados-fundamentos.git
   cd analise-de-dados-fundamentos
   ```
2. **Crie e ative um ambiente virtual:**
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```
3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Inicie o Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
